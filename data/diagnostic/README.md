# data/diagnostic — the diagnostic prompts of record

Generated by `python scripts/make_prompts.py` (deterministic; `icl_copy_reason.tasks.prompts.build(task, 160, seed, ...)`).

| file | what |
|---|---|
| `items_<task>_n160_seed<s>.jsonl.gz` | the 160 items per task (bind_a, bind_b, compose_s, compose_h) and item seed s in {0,1,2,3}; prompt generator seed = s. Seeds 0/1 are the item sets of the first measurements (copy-probability share); seeds 2/3 the fresh-item sets of the re-scoring and head-level analyses. |
| `items_compose_h_n160_seed<s>_ablation_panel.jsonl.gz` | the withheld-combination items of the attention ablation, deletion, layer x position map and head-level analyses: generator seed = s + 11. |
| `items_compose_h_n160_seed<s>_<control>.jsonl.gz` | the alternate presentations (order_ba, demos_1_1, demos_3_3, singles_only, bundles_only, template_alt, code_scheme), seeds 0 and 1. |
| `templates.json`, `pools.json` | the two templates (header, separator, word pairs, ending pool) and the stem / ending / code pools the generator draws from. |

Record fields: `task`, `prompt`, `answer`, `stem`, `ia`, `ib` (feature values), `lang` (the item's language: word pairs, endings, withheld
combination `held`, order, scheme), `demo_stems`, and the donor / counterfactual fields used by activation patching (`donor_prompt`,
`cf_answer`, `sv_prompt`, ...). The copied candidate of a withheld query is the shown combination sharing the first ending
(`tasks.prompts.categorise` -> "competitor"). Licence: CC BY 4.0 (see DATA_LICENSE.md). Size: about 1.3 MB.

The real-language check (tasks/quechua.py) builds its items from the UniMorph `que` lemma list embedded in the module; the UniMorph
file itself (CC BY-SA 4.0, https://github.com/unimorph/que) is not redistributed — place it at `data/diagnostic/unimorph_que` to run
`verify_unimorph`.
